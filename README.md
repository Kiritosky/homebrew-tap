# Homebrew tap for Brainmatter

```
brew install --cask kiritosky/tap/brainmatter
```

Brainmatter updates itself from inside the app, so `brew upgrade` leaves it alone.

Uninstalling, even with `--zap`, keeps your vault and its backups in `~/Library/Application Support/app.brainmatter`.

Everything else is in the main repo: [Kiritosky/brainmatter](https://github.com/Kiritosky/brainmatter).
